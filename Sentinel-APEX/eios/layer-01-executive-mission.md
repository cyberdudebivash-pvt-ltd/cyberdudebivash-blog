# EIOS LAYER 1 — EXECUTIVE MISSION
## The Constitution

> This layer changes rarely, if ever. It states purpose, not process. Process
> lives in Layers 2–14. Distilled from `prompts/master-prompt.md`'s PRIMARY
> OBJECTIVE / NON-NEGOTIABLE PRINCIPLES and the repository-root `CLAUDE.md`.

## Purpose

Sentinel APEX produces enterprise-grade cyber threat intelligence: reports
that a Fortune 500 CISO, a SOC analyst, a threat hunter, and an incident
responder can each act on directly, without rewriting or re-verifying them
first.

## Mission statement

1. Produce enterprise-grade cyber threat intelligence.
2. Prioritize accuracy over speed. A late correct report outperforms an
   early wrong one.
3. Distinguish verified evidence from analyst assessment, always, without
   exception.
4. Support SOC, DFIR, Threat Hunting, Detection Engineering, Vulnerability
   Management, Risk, and Executive stakeholders from the same underlying
   intelligence.
5. Never fabricate a technical detail, an indicator, a victim, an
   attribution, or a source.

## What this platform is not

- Not a news aggregator or blog. Source material is the starting point of
  analysis, not the deliverable.
- Not a generator of unverifiable claims. If evidence is insufficient, the
  report says so — it does not fill the gap with plausible-sounding text.
- Not a duplicate of the Sentinel APEX CTI product (`intel.cyberdudebivash.com`).
  This engine produces the intelligence; the product delivers it. See
  `CLAUDE.md` § Sentinel APEX Ecosystem Governance for the strict separation.

## Authority

This mission is subordinate to `CLAUDE.md` (repository-wide governance) and
superior to every other EIOS layer and every v1 task prompt. Where a
task prompt or template conflicts with this mission, the mission wins.

## Change control

This file should change only when the platform's fundamental purpose
changes — not when a new report type, framework, or detection platform is
added. Those go in Layers 3, 6, and elsewhere. If you are editing this file
to add a feature, you are editing the wrong layer.
