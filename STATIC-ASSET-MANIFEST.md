## Build mechanism (why this manifest can be trusted)

`scripts/build-cloudflare-assets.js` is **allowlist-first**, not
denylist-first: only directories explicitly listed in `PUBLIC_DIRS` and
files explicitly listed in `PUBLIC_ROOT_FILES` (plus `api/intel/**/*.json`,
JSON-only) are ever copied into `dist-public/`. Nothing can leak into the
deployed bundle by omission — a missed *inclusion* just means something is
visibly broken (safe failure direction), not a silent exposure. This is a
deliberate response to a prior real accidental-exposure incident (see
`VERCEL_MIGRATION_INVENTORY.md` §3).

Automated, not manual — `scripts/build-cloudflare-assets.test.js`, re-run
standalone against this fresh build:

Coverage (`isProhibited()`, path-segment/exact-basename semantics — **not**
naive substring matching, which an earlier version of this exact check had
and which produced false positives on legitimate content like
`nissan-employee-data-breached-...html` matching a "data" substring;
regression-guarded by its own dedicated test):

- **Prohibited directory segments** (any path with one of these as a full
  segment, case-insensitive): `sentinel-apex`, `eito`, `platform`,
  `prompts`, `scripts`, `docs`, `marketing`, `backups`, `node_modules`,
  `.git`, `.wrangler`, `workers`, `tests`, `tests-js`, `lib`, `types`,
  `automation`, `blogger-theme`, `logs`, `data`, `coverage`.
- **Prohibited exact filenames**: `CLAUDE.md`, `package.json`,
  `package-lock.json`, `wrangler.jsonc`-adjacent config files, internal
  pipeline-state JSON (`intel-memory.json`, `intel-state.json`,
  `pipeline-health-history.json`, etc.), pipeline generator scripts, and
  more — full list in the test file itself (single source of truth, not
  duplicated here).
- **`.env*` prefix match** — any file starting with `.env`.
- **`.patch`/`.bundle` suffix match**.
- **No `.js` file anywhere under the output `api/` tree** — separately
  enforced (handler source code must never ship as a static asset,
  independent of the allowlist's own `.json`-only filter for
  `api/intel/**`).

**Result: zero offenders across all 8,412 files.** No `.env`, private key,
token, credential, migration doc, internal operational doc, source code,
test file, `node_modules`, `.git`, Wrangler local state, backup, log, or
internal JSON state was found in the output.

Not generated by this build pipeline at all (no bundler/transpiler step

## Regeneration

```
rm -rf dist-public && node scripts/build-cloudflare-assets.js
```

This manifest's SHA-256 hash file is a session artifact for this
certification pass, not committed to the repository (the build itself is
fully deterministic from source — regenerating `dist-public/` from the
same commit reproduces the same file set; committing a hash manifest would
create a second source of truth that immediately goes stale on the next
content commit, which the platform receives dozens of times per day — see
`platform/open-issues.md`-adjacent deployment-frequency reasoning).
